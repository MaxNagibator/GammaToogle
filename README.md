# Gamma Toggle

Маленькая Windows-утилита в трее для изменения гаммы экрана.

## Скачать готовую версию

Откройте раздел **Deploy → Releases** проекта в GitLab, скачайте
`GammaToggle-win-x64.exe` из последнего релиза и запустите. Это автономная сборка
для Windows 10/11 x64: устанавливать .NET не нужно.

Windows SmartScreen может показать предупреждение для неподписанного приложения.
Проверить происхождение файла можно по релизу и исходному коду в этом репозитории.

## Установка и запуск

```powershell
.\Install.ps1
```

Скрипт собирает приложение, запускает его и добавляет ярлык в автозагрузку Windows.
Чтобы не добавлять автозапуск: `Install.ps1 -NoAutoStart`.

## Выпуск новой версии в GitLab

Pipeline проверяет сборку при каждом push. Git-тег формата `v1.0.0` дополнительно
загружает автономный EXE в Package Registry и создаёт GitLab Release:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

## Управление

- `Ctrl + Num0` — следующий уровень по кругу: `1.00 → 2.00 → 3.00 → 1.00`;
- двойной клик по значку в трее — то же самое;
- правый клик по значку — выбрать ступень, открыть настройки или выйти.

В настройках можно задать любое количество ступеней от `0.30` до `5.00` и нажать
новое сочетание клавиш, а также отметить мониторы, на которых должна меняться гамма.
Настройки сохраняются в `%LOCALAPPDATA%\GammaToggle\settings.json`
и подхватываются при следующем запуске.

Переключение происходит без всплывающих уведомлений. Текущий уровень виден при
наведении на значок в трее.

При штатном выходе гамма сбрасывается на `1.00`. HDR, Night Light и некоторые драйверы
видеокарт могут перекрывать программную гамма-кривую.
